- QEMU KVM acceleration, Debian 12 genericcloud guest.
- Key-only guest root SSH: `id` returned uid=0(root).

## Failures found and changes

- Generic cloud kernel with default QEMU NIC: SSH banner timeouts. Virtio NIC fixed it.
- Generated SSH key mode 0644 was refused. Explicit chmod 0600 added.
- Guest shutdown succeeded but a harness check lost its PID because QEMU removes its pidfile. Empty PID handling added. Whole updated harness not rerun yet.
- Snapshot listing against running qcow2 refused write lock. No locking bypass used.
- Cockpit VM-page navigation and administrator escalation still disconnect with a duplicate-channel bridge protocol error. Terminal direct-page works. This is not a completed panel.
- Authenticated desktop container exists, but browser Basic Auth flow not yet verified.
